# Otchet_o_potreb_cofe

CLI-утилита для построения отчётов по CSV-файлам с данными о подготовке студентов к экзаменам.

В рамках тестового задания реализован отчёт `median-coffee`: для каждого студента считается медиана трат на кофе по колонке `coffee_spent` по всем переданным файлам, после чего результат сортируется по убыванию.

## Что поддерживается

- передача одного или нескольких CSV-файлов через `--files`;
- выбор отчёта через `--report`;
- вывод результата в консоль в виде таблицы;
- обработка ошибок пользователя:
  - неизвестный отчёт;
  - несуществующий файл.

## Реализованный отчёт

### `median-coffee`

Считает медиану значений `coffee_spent` для каждого студента по всем переданным CSV-файлам.

## Примеры запуска

Запуск через модуль Python:

```bash
python -m coffee_reports.main --files examples/sample.csv --report median-coffee

Запуск на нескольких файлах:

python -m coffee_reports.main --files examples/sample.csv examples/sample_part_2.csv --report median-coffee

После установки проекта в editable-режиме можно запускать и так:

coffee-reports --files examples/sample.csv --report median-coffee

Проект разделён на небольшие независимые части:

чтение входных данных;

реестр доступных отчётов;

отдельные реализации отчётов;

CLI и вывод результата.

Такая структура позволяет удобно добавлять новые отчёты через параметр --report без изменения основной логики запуска.

В решении использована стандартная библиотека Python для CLI, чтения CSV и расчёта медианы. Для отображения таблицы используется tabulate, для тестов — pytest.
